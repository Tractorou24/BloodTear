# BloodTears

![Logo](https://i.imgur.com/GlsujWz.png)

**BloodTears** is a student-made hack’n slash video game developed under _Unreal Engine 5.4_ as part of our Master’s degree project at _Bordeaux YNOV Campus_.
The project was carried out by a multidisciplinary team of developers, game artists, a game designer, and sound designers.

This repository contains the source code and project files, developed mainly in `C++` and `Blueprints`, with additional tools like FMOD for audio.

## Features

⚔️ Three weapons: dagger (fast), sword (balanced), axe (powerful)  
✨ Unique skills tied to each weapon  
👾 Enemy variety: melee imps, ranged fire skulls, explosive skulls  
📈 XP & leveling system that upgrades attacks and skills  
🕹️ 10-minute gameplay sessions with progressive difficulty  
🛠️ Debug & test tools: in-game logs, cheats, hitbox visualization

## How to Play

⬇️ Download the latest build from the [releases](https://github.com/Tractorou24/BloodTear/releases) page.  
📂 Unzip the archive to your computer.  
▶️ Launch the executable file to start the game.

### Controls:

**ZQSD** → Move  
**Mouse** → Attack  
**Skill** (default: A, E and R) → Trigger weapon skill  
**Space** -> Dash  
**Esc** → Pause menu
